# 💹 Bitcoin Trade Live

"Build a live Bitcoin trade feed. Connect to wss://stream.binance.com:9443/ws/btcusdt@trade using os.network.socket. Each trade arrives as JSON — show a scrolling list of the last 20 trades with price, quantity, and a green (buy) or red (sell) color. Display connection status and reconnect automatically on close
