# 📊 Political Trends Dashboard

Build a "Political Trends Dashboard" app that displays the latest political trends, news, and developments. The app should:

1. Fetch and display current political news headlines from multiple perspectives/sources
2. Show trending topics/tags in politics (e.g., elections, policy debates, international relations)
3. Include a clean, modern dashboard layout with cards for different categories (US Politics, International, Policy/Legislation, Elections)
4. Have a search/filter bar to narrow by topic or region
5. Display timestamps and source attribution for each item
6. Use a professional color scheme suitable for news consumption

Since we can't do real-time web fetching from the app itself, simulate realistic political trend data with a mix of current-style headlines and make it look polished and functional as a dashboard UI.
