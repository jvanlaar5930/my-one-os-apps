# 🎯 Click Counter

Create a click counter game. A large button in the center that increments a counter each time clicked. After each click, the button changes to a random color. When the counter reaches 10, display a big 'Goal Reached!' message and reset the counter back to 0. Keep the UI clean and minimal.
