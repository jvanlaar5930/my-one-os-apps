# 📈 Crypto Ticker

Build a live crypto price ticker using os.network.fetch. Fetch Bitcoin and Ethereum prices from https://api.coingecko.com/api/v3/simple/price?ids=bitcoin,ethereum&vs_currencies=usd every 15 seconds. Show price and a green/red indicator for the direction of the last change.
