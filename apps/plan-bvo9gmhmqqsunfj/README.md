# 🔄 Binary Roundtrip Tester

Build an app that tests binary file round-trips. It should: draw a small pattern on a canvas, export it as a base64 PNG, save it with os.fs.writeBinary, read it back with os.fs.readBinary, create a blob URL with os.assets.createUrl, and display it in an img tag. Show each step's status on screen.
