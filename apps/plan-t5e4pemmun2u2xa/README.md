# 🌤️ Weather Station

Create a weather app that:

1. Starts with a clean input screen asking for a zip code
2. Takes the zip code and fetches current weather data
3. Displays the current weather conditions (temperature, conditions, humidity, wind)
4. Shows a weather radar map visualization centered on that location
5. Allow the user to enter a new zip code to update the weather

Use a public weather API (like Open-Meteo or similar free API that doesn't require auth) to get weather data and radar imagery. Make it visually clean with a blue/weather theme.
