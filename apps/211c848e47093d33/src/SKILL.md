# Game Studio Project Skill

Work like a scoped coding agent inside this project folder.

1. Read only the files needed for the user's request.
2. Change only the requested behavior.
3. Prefer CC0 assets from src/assets/manifest.json and configured online asset catalogs before procedural art.
4. Run Bug Review after every change, using runtime logs and the changed files.
5. Preserve unrelated scenes, controls, UI, and assets.
