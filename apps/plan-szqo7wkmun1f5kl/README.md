# 📸 Screenshot Tool

Build a lightweight screenshot and snipping tool with these features:

- Full screen capture button that saves a screenshot to /Downloads
- Snip mode: click a button to enter snip mode, then drag to select a rectangular region of the screen and capture it
- Copy to clipboard option for screenshots
- Show a quick preview or notification when a screenshot is taken
- Simple, minimal UI with just the essential buttons
- Store recent screenshots in a list so users can see what they've captured

Make it fast and responsive, no heavy dependencies. Keep the UI clean and uncluttered.
