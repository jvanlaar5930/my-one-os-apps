# 📊 CSV Editor

Create me an excel like application to manage data. I want it only to deal with CSV formats. I should be able to open the CSV file, save/save as the csv file, and create new CSV. 

Opening existing CSV allows for quickly adding a Header row (or quickly removing). I should be able to modify each data item in a editable cell (just like excel). I should be able to highlight 1 or many cells. I should be able to click to drag to highlight a block of cells. There should be formatting options. I should be able to do rudimentary calculations - for example Row 2:A + Row 2:B = Row 2:C. I should be able to highlight cells and change their colors. I should be able to format highlighted cells to have built in formatting. 

This program should have direct access to you, allowing for direct manipulation of the CSV data and modifications.
