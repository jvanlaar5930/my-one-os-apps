A calculator app that performs basic arithmetic operations with a clean, intuitive interface.

Features:
• Basic operations (addition, subtraction, multiplication, division) with keyboard support
• Decimal point handling and error prevention for invalid operations
• Clear button to reset calculations and memory
• Display showing current input and calculation results
• History panel to review previous calculations
• Responsive design that works on all screen sizes

Bridge & data:
os.storage.save and os.storage.load for persisting calculation history
os.window.resize for responsive layout adjustments

Layout:
Single main display area with calculator buttons arranged in a grid pattern below
