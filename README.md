# my-one-os-apps

Apps built with **one_OS** — each lives in `apps/<name>/` with its build plan (`plan.md`) and a self-contained `index.html`.

| --- | --- | --- |
| 🧮 | [Calculator](apps/calculator/) | A calculator with basic arithmetic and keyboard support. |
| 📅 | [Calendar](apps/calendar/) | A calendar with month and week views, per-day events added via a hover + on each day, and a light/dark theme toggle. |
| ⏰ | [Clock](apps/clock/) | A clock app with a live clock, stopwatch, and countdown timer. |

There are 3 differnet coisn you can get, the further you progress you can find very rare Large coins which equal 10, medium rarity which equal 5, and common equal 1. Your score is just Time * Coin amount. The character should look like a cowboy. The name of the game should be called Roudy the Rancher. |
